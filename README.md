# Городская доставка — Томск

Веб-платформа управления городской доставкой, заказами, курьерами и парком электровелосипедов.

## Статус

Проект находится на этапе создания MVP.

## Основные условия

- регион работы: Томск;
- только безналичные расчёты;
- выплаты курьерам перечислением за выполненные заказы;
- адаптивный веб-интерфейс;
- минимальные расходы на разработку и инфраструктуру.
